# Product clarifications after the first backlog cleanup

September 26, 2026. Records the user's clarification of the earlier notes. This supplements the retrospective rather than rewriting its historical snapshot.

- Confirmed additions: complete more theory lessons first, then add more personalized settings. Specific preference behavior needs design.
- Markup after layout changes is implemented and needs verification. Much of the immediate remaining work is iPad behavior testing and playing with a real flute, not another implementation pass.
- Existing session/history behavior should be tested before changing it. The earlier source-audit concern does not authorize restoring or redesigning the timer.
- “Settings outer range” may have meant a global playable-note range for a student. Its use case is no longer remembered, so it is set aside.
- “Smart Drum” is interpreted as the earlier smart drone: the reference pitch changes with the music as the player moves between measures while using the metronome. The source of the appropriate pitch and measure progression still need design.
- “Technical checklist” means selecting measures from different pieces and saving them as a browsable collection of technical practice cards.
- Transposition is a substantial individual feature and must remain visible, with its own description. Do not bury it in a compressed list of nouns.
- Offline use means saving sheet music locally for access on iPad without Wi-Fi.
- Cross-device continuity means retaining user settings and practice information between iPad and laptop. Authentication, data storage and sync support that goal.
- The desired practice library resembles Goodreads: planned, current and past material, with actual playing activity tracked. Merely opening a score is not established evidence of playing.
- The current app feels scattered. A guided practice experience needs product design first, while preserving a direct sheet-music-library experience for users who prefer it.
- The unidentified iPad “bar” and generic MusicXML cleanup remain set aside.
